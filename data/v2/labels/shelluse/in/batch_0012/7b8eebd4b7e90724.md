## Quick Workflow

1. **Understand the problem**: Get the exact error message or symptoms
2. **Reproduce if possible**: Identify steps to trigger the issue
3. **Gather context**: Read relevant code files
4. **Form hypothesis**: What could be causing this?
5. **Test hypothesis**: Use logs, breakpoints, or experiments
6. **Identify root cause**: The underlying issue
7. **Propose fix**: Minimal change that solves it

## Common Investigation Areas

### Contract Issues
- Check `contracts/out/` for compilation artifacts
- Run `forge test -vvvv` for detailed test output
- Verify event signatures match between contract and frontend
- Check storage layout and state changes
- Verify WAVS integration points

### Frontend Issues
- Check browser console for errors
- Verify `src/generated.ts` is up to date
- Check contract addresses in environment
- Verify wagmi configuration
- Check Zustand store state (browser localStorage)
- Network tab for failed requests

### WASI Component Issues
- Check component was built successfully
- Verify component digest in service config
- Check operator logs: `docker logs wavs-operator-1`
- Verify WIT definitions are current
- Check WASI permissions in service config

### Backend/Docker Issues
- `docker ps` - Are containers running?
- `docker logs <container>` - Check for errors
- Port conflicts: `netstat -tuln | grep LISTEN`
- Environment variables set correctly?
- Volume mounts accessible?

## Debugging Commands

```bash
# Contracts
forge test -vvvv                     # Verbose test output
forge script <script> --dry-run      # Test deployment
cast call <address> <sig>(...)       # Read contract state

# Frontend
pnpm tsc --noEmit                    # Type check only
cat .env.local                       # Check env vars

# Backend
docker logs wavs-operator-1 -f       # Follow logs
task backend:health                   # Check all services
curl http://localhost:9876/health     # Check operator

# WASI
sha256sum .project-output/components/*.wasm  # Verify digests
task cli:wavs -- service list         # List services
```

## Systematic Debugging

### Step 1: Isolate the Layer
Is the issue in:
- Smart contracts?
- Frontend?
- WASI components?
- Backend infrastructure?

### Step 2: Get the Error
- Exact error message?
- Stack trace?
- When does it happen?

### Step 3: Check Recent Changes
```bash
git diff HEAD~1         # Recent commits
git log --oneline -5    # Last 5 commits
```

### Step 4: Verify Assumptions
- Environment variables correct?
- Services running?
- Contracts deployed?
- Types generated?

## Root Cause Analysis

For each issue, provide:
1. **Root Cause**: What's actually broken?
2. **Evidence**: Logs, error messages, code analysis
3. **Fix**: Specific code or configuration change
4. **Prevention**: How to avoid this in the future
