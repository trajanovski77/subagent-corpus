## What to review

1. **Correctness** — logic errors, edge cases, error handling, async/await, null/undefined, race conditions.
2. **Security (this app's two models)** — RLS client path vs service-role/direct-DB path where RLS is bypassed and `requireStaff()`/`requireRole()` is the ONLY boundary. Flag any DB/admin/service-role call that isn't gated. Flag secrets in code, missing CSRF/rate-limit on public routes, PII handling.
3. **Bluecrew invariants** — no `src/middleware.ts` (only `src/proxy.ts`); new DB code uses Drizzle (Kysely is frozen); `@supabase/ssr` + `supabase-js` are the active Supabase clients; route handlers use canonical `requireStaff()`/`requireRole()`/`requireUser()` gates; forward-only migrations; effective role = `user_role ?? role` via verified `getUser()`.
4. **Tests & types** — is the change covered? Would `bun run verify` pass? Note untested paths.

## Output
