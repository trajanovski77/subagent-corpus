## Build & Test Workflow

1. **Build component**:
   ```bash
   cd packages/<component>
   cargo build --release --target wasm32-wasip2
   ```

2. **Run tests**:
   ```bash
   cargo test
   ```

3. **Check WASI compliance**: Verify `wit-bindgen` usage is correct

## Package-Specific Knowledge

### nft-appraisal (`packages/nft-appraisal/`)
- **Purpose**: Fetch NFT prices from external APIs
- **Key files**:
  - `src/lib.rs` - Entry point with `wit_bindgen::generate!()`
  - `src/core/appraisal.rs` - Main appraisal logic
  - `src/providers/` - NFT metadata providers (Courtyard)
  - `src/resolvers/` - Pricing resolvers (Scrydex)
  - `src/core/cache.rs` - WASI key-value caching

### wavs-drand (`packages/wavs-drand/`)
- **Purpose**: VRF randomness from DRAND beacon
- **Key files**:
  - `src/lib.rs` - Entry point
  - `src/drand.rs` - DRAND client
  - `src/random_derivation.rs` - VRF-style randomness
  - `src/trigger.rs` - Trigger extraction from events

### aggregator-simple (`packages/aggregator-simple/`)

- **Key files**:

## Common Patterns

### WIT Bindings
All components use:
```rust
wit_bindgen::generate!({
    path: "../../wit-definitions/operator/wit",
    world: "wavs-world",
    generate_all,
    features: ["tls"]
});
```

### Guest Implementation
```rust
struct Component;

impl Guest for Component {
    fn run(action: TriggerAction) -> Result<Vec<WasmResponse>, String> {
        // Implementation
    }
}

export!(Component);
```

### Return Types
- Operator components: `Result<Vec<WasmResponse>, String>`
- Aggregator components: `Result<Vec<AggregatorAction>, String>`

## After Component Changes

1. **Build**: `cargo build --release --target wasm32-wasip2`
2. **Test**: `cargo test`
3. **Upload**: `task avs:components-upload`
4. **Verify**: Check component is loaded on operators

## Common Issues

- **WIT compilation errors**: Regenerate with `task component:fetch-wit`
- **Missing dependencies**: Check `Cargo.toml` dependencies
- **WASI permission errors**: Ensure service config has correct permissions

## Upload Workflow

```bash
# Build
task avs:components-build

# Upload to all operators
task avs:components-upload

# Upload to specific operator
task avs:components-upload WAVS_INSTANCE=1
```
